# NCC-themed public homepage

The public homepage is served at `/` and `/home-military`. The previous homepage remains available at `/home-classic`. Admin and student portal routes are unchanged.

## Visual identity

The theme follows the NCC emblem's red, dark blue, light blue, and gold. Navy surfaces, red calls to action, sky-blue headings, gold achievement details, and a three-colour identity stripe replace the former orange/black palette. UI colours are chosen for readability rather than presented as an official NCC colour specification.

The public layout was initially inspired by the BlackHawak template's hero slider and section structure, implemented in React without importing its source package. It now uses authentic OTA Gwalior photography instead of the generated cadet portrait and stock adventure imagery.

## Institutional naming

The website name is **NCC OTA Gwalior**, with **Officers’ Training Academy** as the subtitle. Affiliation programs and certificate access are described in page content rather than included in the name. The naming is consistent across public pages, sign-in, participant/admin workspaces, recovery emails, page metadata, and the default organization heading for future certificate generation. Already issued PDF files are not regenerated by a branding change.

The homepage's primary action and navigation link open the authenticated certificate page. Anonymous participants return to their requested certificate page after successful sign-in; a role-specific destination check prevents a student sign-in from navigating to an admin-only path.

## Ngrok sign-in

Rails HostAuthorization checks forwarded hostnames as well as the Host header. The demo hostname `squander-pasture-whoops.ngrok-free.dev` is explicitly permitted in development. Override the comma-separated `DEV_ALLOWED_HOSTS` environment variable before starting Rails if the hostname changes. The setting does not affect production, and CSRF protection remains enabled.
